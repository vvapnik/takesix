# Agents

This repository is developed with the help of [Claude Code](https://claude.com/claude-code)
(Anthropic). Commits are authored and reviewed by the maintainer.

It holds the TakeSix landing page and live demo, deployed to GitHub Pages from `main`.
The original prototype app is on the `legacy` branch. The libraries live in
[takesix-core](https://github.com/vvapnik/takesix-core),
[takesix-react](https://github.com/vvapnik/takesix-react) and
[takesix-agent](https://github.com/vvapnik/takesix-agent).

- The site uses the published npm packages, never local `file:` links.
- After editing `src/takesix.takesix.json`, run `npm run validate`.
- Commits follow Conventional Commits, as in takesix-core's CONTRIBUTING.md.
